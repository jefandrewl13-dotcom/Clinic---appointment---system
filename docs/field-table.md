
# Clinic Appointment System
## Form Field Table

| Field Name | Control Type | Required | Validation Rule |
|---|---|---|---|
| Full Name | Text Field | Yes | Minimum 3 characters |
| Email Address | Email Field | Yes | Must be a valid email |
| Contact Number | Telephone Field | Yes | Must contain 11 digits starting with 09 |
| Age | Number Field | Yes | Must be between 1 and 120 |
| Gender | Radio Buttons | Yes | Must select one option |
| Doctor | Select List | Yes | Must select a doctor |
| Appointment Date | Date Picker | Yes | Cannot be a past date |
| Appointment Time | Select List | Yes | Must select a time |
| Reason for Consultation | Text Area | Yes | Minimum 5 characters |
| Confirmation | Checkbox | Yes | Must be checked |

## Purpose

This table describes the input fields used in the
CarePoint Clinic Appointment System, including their
control types, required status, and validation rules.
